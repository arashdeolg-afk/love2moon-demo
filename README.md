# love2moon — demo preview

This is a static **demo build** of the love2moon "Moonlit Night" redesign, published for preview on GitHub Pages.

- Runs entirely in the browser with a pretend couple and **mock data**.
- No real accounts, messages, database, backend or keys are included; sign-in is not required.
- Source code lives in a separate private repository.

Live preview: https://arashdeolg-afk.github.io/love2moon-demo/
